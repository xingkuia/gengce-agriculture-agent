# 3–5 分钟演示脚本

## 0:00–0:25 开场

打开 `release/Gengce-win32-x64/Gengce.exe`，说明这是预置演示账号直接进入的桌面农业 Agent 助手，不是浏览器工作台或营销页。左侧展示最近对话、一个账号下的两个基地和地块；中部只有一个对话入口；只有点击执行轨迹时才打开中性的“运行与产出”面板。

## 0:25–0:55 地块条件

在输入框询问“结合东坡田的位置和当前条件，本季种什么更合适？”指出对话中的位置、42 亩面积、稻油轮作、天气来源与土壤状态。强调天气来自 Open-Meteo；土壤请求失败时系统不会假装成功，而会显示“区域先验，需要测土校准”。

## 0:55–1:30 分目标选种

依次切换“稳健收益、低风险、省工易管、养地轮作”，展示候选顺序如何变化。说明决定权在用户，不是系统给出一个隐藏综合分。

展开“本地行情”并输入当地收购价、亩产和成本，说明公共数据只是估算，用户本地值优先，并在同一对话中重新计算候选。

## 1:30–2:20 Agent 运行与自我修复

点击“执行轨迹”，观察“运行与产出”面板：

1. Orchestrator 生成 DAG；
2. Weather 与 Soil 并行取证；
3. A2A 合并证据；
4. 选种、经济、农艺依次执行；
5. Verifier 发现土壤先验尚未进入正式作业；
6. Mastra Workflow 触发局部修复；
7. 第二轮校验通过。

打开任一“查看结构化产物”，说明运行不是动画，而是 SSE 实时事件并已写入 SQLite，刷新后仍可回放。

## 2:20–2:50 建立方案

选择“冬小麦”，点击“采用这个方案”。随后从对话中的下一步操作打开“种植方案”抽屉，快速展示整地、播种、苗期、越冬、春季管理、收获和天气复核任务。

强调这些任务都可以在农事台账中对应到实际行动，而不是一篇无法执行的建议。

## 2:50–3:25 农事记录

从下一步操作打开“农事记录”抽屉，展示已完成和待执行作业。新增一次播种或雨前清沟记录，说明计划与实际差异会被保留。

## 3:25–4:00 结果与反馈

从对话或当前工作区打开“结果复盘”。说明收获后可以填写实际产量、品质、收入和成本，并进行评分。保存后方案变为已完成，结果进入地块历史，反馈进入后续评估候选集。

## 4:00–4:30 评估中心与区别总结

从次级入口打开“Agent 评估”，展示 Mastra Agent/Workflow、MCP 工具、A2A、独立校验、修复预算和固定回归集。

收尾时强调三件事：

- 不是模块堆叠的工作台，而是单一对话驱动的桌面 Agent；
- 不是单 Agent 聊天，而是可回放多 Agent 协作；
- 不是黑箱综合分，而是分目标选择与证据透明；
- 不是一次性建议，而是方案、执行、结果、反馈的完整闭环。
